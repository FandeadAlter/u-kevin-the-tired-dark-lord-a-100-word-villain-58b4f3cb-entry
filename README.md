Entry for [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/c/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) on make.fun.

One monologue of exactly 100 words (493 characters), spoken by a fantasy villain two hundred years into a curse, with one verse left to finish. The tiredness lives in the rhythm, the pauses and the small deflections — the stairs, the cold tea, the ravens that stole his notes — never in a plain statement that he is weary. The program writes the monologue to `/output/entry.txt`.

Run it with Node 22:

```sh
node main.ts
```
